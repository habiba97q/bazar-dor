# 🛒 বাজার দর (Bazar Dor)

নিত্যপ্রয়োজনীয় পণ্যের নির্ভরযোগ্য দৈনন্দিন বাজার দর এবং বাজারভিত্তিক দামের তুলনামূলক ওয়েব প্ল্যাটফর্ম।

## 🔗 লিংকসমূহ
- **লাইভ সাইট**: [https://bazar-dor-orcin.vercel.app](https://bazar-dor-orcin.vercel.app)
- **গিটহাব রিপোজিটরি**: [https://github.com/habiba97q/bazar-dor](https://github.com/habiba97q/bazar-dor)

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ
- **Frontend**: Next.js 16 (App Router), React 19, Tailwind CSS
- **Authentication**: BetterAuth (Email/Password, Google, GitHub)
- **Database**: MongoDB Atlas
- **Icons & UI**: Lucide React, React Hot Toast

## ✨ মূল ৫টি ফিচার
1. **লাইভ প্রাইস টিকার**: ওয়েবসাইটের শীর্ষে চলমান ইনফিনিট টিকার যেখানে পণ্যের আজকের দাম ও পরিবর্তনের হার (▲/▼) প্রদর্শিত হয়।
2. **দাম বাড়া ও কমার প্রবণতা**: আজকের বাজারে শীর্ষ মূল্যবৃদ্ধিকারী (আজ দাম বেড়েছে ▲) এবং মূল্যহ্রাসকারী (আজ দাম কমেছে ▼) পণ্যের আলাদা তালিকা।
3. **ক্যাটাগরি ও সর্টিং**: বিভিন্ন ক্যাটাগরি ফিল্টার এবং বাংলা সংখ্যাসূচক মানের ভিত্তিতে দাম কম থেকে বেশি বা বেশি থেকে কম সাজানোর সুবিধা।
4. **সুরক্ষিত প্রডাক্ট বিবরণী ও বাজার তুলনা**: বিস্তারিত পণ্যের বিবরণ শুধুমাত্র লগইন করা ইউজারদের জন্য উন্মুক্ত এবং এতে বিভিন্ন বাজারের সর্বনিম্ন, সর্বাধিক ও গড় দামের তুলনা তালিকা রয়েছে।
5. **ইউজার একাউন্ট ও প্রোফাইল আপডেট**: ইমেইল বা গুগল/গিটহাব দিয়ে সাইন-ইন এবং প্রোফাইল থেকে সহজেই নিজের নাম আপডেট করার সুবিধা।

## 🚀 লোকাল কম্পিউটারে রান করার নিয়ম

১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/habiba97q/bazar-dor.git
cd bazar-dor
```

২. প্যাকেজ ইনস্টল করুন:
```bash
npm install
```

৩. সার্ভার চালু করুন:
```bash
npm run dev
```

ব্রাউজারে ভিজিট করুন: `http://localhost:3000`
